# Mekanism Rust

Um mod para o [Horizon](https://playhorizon.dev) (Minecraft Java 26.3 em Rust) que reúne o Mekanism e
seus addons em um mod só. O jogador escolhe nas configurações quais módulos ficam ligados.

Status: **desenho**. Ainda não há código. Veja [DESENHO.md](DESENHO.md).

## Créditos

Este projeto é um port independente, escrito do zero em Rust, de ideias e conteúdo de mods Java. Os
projetos originais e seus autores:

- [Mekanism](https://www.curseforge.com/minecraft/mc-mods/mekanism): bradyaidanc e equipe
- [Mekanism Generators](https://www.curseforge.com/minecraft/mc-mods/mekanism-generators),
  [Tools](https://www.curseforge.com/minecraft/mc-mods/mekanism-tools),
  [Additions](https://www.curseforge.com/minecraft/mc-mods/mekanism-additions): bradyaidanc e equipe
- [Mekanism More Machine](https://www.curseforge.com/minecraft/mc-mods/mekanism-more-machine): lost_myself8
- [Evolved Mekanism](https://www.curseforge.com/minecraft/mc-mods/evolved-mekanism): iglee42 e WoXayZ
- [Mekanism Unleashed](https://www.curseforge.com/minecraft/mc-mods/mekanism-unleashed): WhitePhantom
- [Iglee's Library](https://www.curseforge.com/minecraft/mc-mods/iglee-library): iglee42, usada pelo
  Evolved Mekanism original. Este projeto não a inclui nem depende dela.

mantidos onde o código ou conteúdo deles for portado. Este projeto não é afiliado aos autores
