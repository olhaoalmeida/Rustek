# Pasta de referência (ignorada pelo git)

Coloque aqui, **só na sua máquina**, os jars e códigos dos mods originais para estudo. Tudo desta pasta,
menos este arquivo, é ignorado pelo git (`.gitignore`) e nunca deve ser enviado ao repositório.

Antes de copiar qualquer coisa daqui para o projeto, confirme a licença e registre a origem em
`NOTICE.md`.
